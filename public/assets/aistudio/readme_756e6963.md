# Invoice Flex — GST billing for small workshops

A PHP + MySQL billing app: customers, GST invoices (CGST/SGST or IGST), a printable
A4 tax invoice, payment tracking, and an admin console for memberships.

## Running it

1. Copy the `minorpjc` folder into `C:\xampp\htdocs\`.
2. Start Apache and MySQL in XAMPP.
3. Import `invoice_db.sql` in phpMyAdmin if you have not already.
4. Open `http://localhost/minorpjc/index.php`.

The first page load adds the `payments` table and the two new columns by itself.
`upgrade.sql` contains the same statements if you would rather run them by hand.

Members sign in with a six-digit code shown on screen. The admin
(`abhipan0011@gmail.com`) signs in with a password and lands on the console.

## What changed in this version

**Membership status is no longer typed in.** It was possible to leave a member on
"Expired" while their plan ran to next month — the status dropdown and the date
disagreed. The status is now worked out from the end date every time it is read
(`membership_state()` in `config.php`). Extend a plan and the account is live
again immediately; let the date pass and it locks itself. The admin table has no
status dropdown any more, just the plan, the date, and quick +1 month / +6 months
/ +1 year buttons.

**Payments.** A new tab shows, for each company, what was billed, what came in and
what is still owed — plus a "50% advance" chip when roughly half has been paid. A
payment can be recorded against any invoice, several times over, and undone. An
advance can also be captured while the invoice is being created. The printed bill
shows the received amount and the balance due once anything has been paid.

**Round profile picture.** Company profile takes a picture that appears as a round
avatar in the sidebar and on the profile page. The invoice logo is a separate
upload, so the printed bill keeps its own artwork.

**Plan limits are enforced.** They live in `$PLAN_LIMITS` at the top of
`config.php`:

| Plan | Invoices a month | Customers |
| --- | --- | --- |
| Free | 5 | 10 |
| Pro | 50 | 200 |
| Enterprise | unlimited | unlimited |

Usage shows on the dashboard, a warning appears as the cap approaches, and the
invoice builder stops at the limit. Change the numbers in one place and the whole
app follows.

**Fresh interface.** One stylesheet (`assets/css/app.css`) in place of the ten it
used to have: grouped white cards on a soft grey background, a dark rounded
sidebar, a translucent top bar, pill chips and sheet-style dialogs.

**Fixes along the way.** Invoice totals are recalculated on the server instead of
being trusted from the browser; the customer GSTIN lookup used a column name that
does not exist (`gstin` instead of `gst_number`); deleting an invoice now clears
its items and payments; customers can be edited and removed; and the state on the
company profile drives the CGST/SGST versus IGST decision rather than being fixed
to Gujarat.

## Files

| File | What it does |
| --- | --- |
| `config.php` | Connection, plan limits, membership and payment helpers, schema check |
| `partials/layout.php` | Sidebar, top bar and page shell shared by every screen |
| `index.php` | Sign in and sign up |
| `setup.php` | First-run company details |
| `dashboard.php` | Money position, plan usage, recent invoices |
| `customer.php` | Customer directory with add, edit and remove |
| `invoices.php` | Every invoice grouped by month |
| `invoice-create.php` | Invoice builder with GST and an optional advance |
| `print-invoice.php` | A4 tax invoice for print or PDF |
| `payments.php` | Who has paid, who is part paid, who owes |
| `profile.php` | Company details, bank details, profile picture |
| `admin_dashboard.php` | Member list, plans and end dates |
| `upgrade.sql` | The schema change, written out |

## Requirements

Apache, PHP 8.0 or newer, MySQL or MariaDB. Tested against the XAMPP defaults
(PHP 8.2, MariaDB 10.4).
